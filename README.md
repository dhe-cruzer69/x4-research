## Principle

Every important claim must carry source, evidence, confidence, and contradiction checks.

```
QUESTION
  ↓
PLANNER → SEARCH → SOURCE RANKING
  ↓
EVIDENCE EXTRACTION → CLAIM GRAPH
  ↓
CONTRADICTION DETECTION → CITATION VALIDATION
  ↓
SYNTHESIS → REPORT
```
